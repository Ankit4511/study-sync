# 📚 StudySync

A modern and responsive educational landing page built to showcase a digital learning platform. StudySync is designed to provide students with a seamless learning experience through a clean UI, engaging sections, and responsive design. The project focuses on creating an attractive user interface for an EdTech platform.

## 🚀 Live Demo

https://study-sync-cyan-three.vercel.app/

## 📌 Overview

StudySync is a responsive multi-section landing page that highlights the features and benefits of an online learning platform. It includes a modern hero section, feature highlights, testimonials, newsletter subscription section, and a polished user experience across all devices.

## ✨ Features

* Responsive design for all screen sizes
* Modern and clean UI
* Hero section with call-to-action buttons
* Feature showcase section
* Testimonials section
* Newsletter subscription section
* Smooth layout and spacing
* Reusable component structure
* Fast loading and optimized assets

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Responsive Design
* Vercel Deployment
